1. **橫波是什麼**：橫波是指，當物體受力後波動方向(物體位移)與能量(機械能)傳播的方向是垂直的。我們可以依靠以下兩個公式來說明動能與位能之間的關係。
	1. **動能**：$$u_K=\tfrac12\,\mu\left(\frac{\partial y}{\partial t}\right)^2$$ </br> 
	> 這是「每單位長度的動能密度」。$\mu$ 是繩子的線密度，$y(x,t)$ 是橫向位移。
	2.  **位能：** $$u_P=\tfrac12\,T\left(\frac{\partial y}{\partial x}\right)^2$$</br>
	> T 是張力。局部斜率 $\partial y/\partial x$ 讓繩子微微被拉長，於是儲存彈性能。
2. **為什麼波形在時間增加時會「平移」而不是改變形狀**：位移應該固定的上下距離，但物質會依據能量傳遞的方向移動，所以形狀是因為橫波的上下幅度去決定形狀，而上下頻率是固定的所以一樣的圖形會被能量往前帶走，所以會保留圖案並且平行移動。但條件是：
	- 無色散
	- 阻尼小到幾乎可以忽略不計
	- 非線性：波的形狀非常不均勻
    
3. **如何判斷波是往正 x 還是負 x 方向移動**：我的想法是：移動到的最後位置＝剛開始的位置 加上 速度 $*$ 時間(代表從A -> B 的中間的速度跟花費時間可以得到距離=>這樣就是往 $+x$ 方向)。
	- $f(x - vt)$（就是右移）→ **最後 = 起始 + vt；起始 = 最後 - vt**。
	- $f(x + vt)$（就是左移）→ 由 x+vt=x0x + vt = x_0x+vt=x0​ 得 **最後 = 起始 − vt；起始 = 最後 + vt**。
4. **d’Alembert 兩式的差異**：</br>一般式： $$y(x,t) = f(x - vt) + g(x + vt), \quad v = \sqrt{\dfrac{T}{\mu}} > 0$$
	因為波動方程是線性的，任何一種解都可以分解成 **往左+往右** ，所以，這也告訴了我為什麼要有兩個式子：例如，駐波就是一個很好的例子，當自由端的橫波傳遞至固定端，固定端也會傳遞能量回自由端。這也更加證實了，**正負符號只是改變方向，並不會改變這個橫波的形狀。**。
