## ① 滑輪系統（pulleys）

**核心觀念：**

- **同一條繩子 → 張力相等**
    
- **對每一個物體／滑輪畫受力圖 → 寫力平衡**
    

**常用公式：**

- 如果一個滑輪被兩段繩子往上拉，另一條繩子往下拉：
    
    $$T_\text{down} = T_\text{up1} + T_\text{up2}$$
- 重物平衡：
    
    $$T = Mg$$
- 手拉力 FF：等於該繩段張力
    

**舉例（這題）**

$$T_1 = T_2 = T_3 = \frac{Mg}{2},\quad T_5 = Mg,\quad T_4 = Mg,\quad F = \frac{Mg}{2}$$

## ② 拐杖（crutches at an angle）

**核心觀念：**

- 地面的反作用力 RR 沿著拐杖方向
    
- 分解成垂直/水平分量：
    
	$$R \cos \theta = \text{垂直支持力},\quad R \sin \theta = \text{水平摩擦力}$$

**常用公式：**

- **最小摩擦係數**：
    
	$$\mu_{\min} = \tan \theta$$
- **壓縮力（沿拐杖的力）**：
    
	$$R = \frac{F_\text{vertical}}{\cos \theta}$$

（其中 $F_\text{vertical}$ 是每支拐杖要承受的垂直分量）

## ③ 煞車距離（braking distance）

**核心觀念：**

- 最大摩擦力：
    
    $$f_{\max} = \mu_s mg$$
- 最大減速度：
    
    $$a = \mu_s g$$
- 運動學公式（煞停）：
    
	$$v^2 = 2ad \ \ \Rightarrow \ \ d = \frac{v^2}{2 \mu_s g}$$

---

**總結重點：**

1. **滑輪** → 繩子同張力，對每個物體寫力平衡。
    
2. **拐杖** → 斜角支撐，分解垂直/水平，摩擦比值給 $\mu = \tan\theta$。
    
3. **煞車** → 摩擦提供減速度，公式 $d=v^2/(2\mu g)$。
