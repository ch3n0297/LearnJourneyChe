# Courses Directory Policy

All course folders follow the same first-level layout to keep organization predictable:

- `notes/`
- `homework/`
- `labs/`
- `projects/`
- `datasets/`
- `reports/`
- `assets/`
- `references/`
- `archive/`

When adding new content, place it in the matching category first; avoid creating new first-level folders unless necessary.
