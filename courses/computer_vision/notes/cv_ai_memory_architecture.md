# 2D 網頁遊戲即時輔助瞄準（Aim Assist）

## 專題一頁摘要

- **題目**：以 YOLOv10 實作 2D 網頁遊戲之即時「敵人偵測＋輔助瞄準」
    
- **情境**：自建或明確授權的單機／訓練關卡之 **2D 網頁遊戲**
    
- **核心機制**：Canvas 擷取 → YOLOv10 偵測 →（選靶/追蹤）→ PD/α-β 平滑 → 移動**遊戲內準星**（非 OS 滑鼠）
    
- **操控**：`T` 開/關輔助；`←/→` 切換目標；玩家自行射擊
    
- **合規**：不控制作業系統游標、不繞反外掛；僅限自有/授權環境
    

---

## 預期達成效果（對應 a）

- 可切換的**Aim-Assist 原型**（即時疊加偵測框與準星）
    
- **效能**：偵測 ≥ 20–30 FPS（輸入 512×288）
    
- **操控品質**
    
    - 取靶時間（出現→準星貼合中心）**中位數 ≤ 300 ms**
        
    - **命中率 +15～30%**（相對無輔助）
        
    - **誤鎖率 ≤ 5%**
        
- 成果：Demo 影片、開源程式碼、技術報告（含指標與方法）
    

---

## 方法、模型、演算法與套件（對應 b）

- **偵測模型**：YOLOv10（nano/tiny 等級；Ultralytics 版本）
    
- **選靶/追蹤（擇一或併用）**
    
    - 簡化規則：距離準星最近／威脅度排序＋`←/→` 人為切換
        
    - 輕量追蹤：SORT / ByteTrack（簡化版）
        
- **平滑控制**：PD 控制器 + α-β（指數）濾波
    
    - 加入**死區**與**最大速度**，避免抖動與過衝
        
- **部署路線**
    
    - **A. 本機後端**：FastAPI + Ultralytics（前端每 33–50 ms 傳 512×288 圖）
        
    - **B. 全前端**：ONNX Runtime Web（WebGPU/wasm）載入量化 ONNX
        
- **主要套件**：`ultralytics`、`fastapi`、`uvicorn`、（可選）`onnxruntime-web`、前端 Canvas/Phaser/Pixi.js
    

---

## 資料來源、數量、可得性（對應 c）

- **來源**
    
    1. 自建／授權之 2D 網頁遊戲**錄影抽幀**
        
    2. **合成資料**：敵人 sprite + 隨機背景/遮擋/HUD 噪聲（自動輸出 YOLO 標註）
        
- **規模**
    
    - **手標 600± 張**（先只做「角色」一類即可達成 MVP）
        
    - 合成擴增至 **2,000～3,000 張**；必要時再補錄影抽幀
        
- **可得性與版權**：皆為自產或授權素材；YOLO 標註（txt）通用
    

---

## 系統架構（端到端）

```
Canvas 擷取(512×288)
   → YOLOv10 偵測 (Top-N)
      → 選靶/追蹤（最近準星／SORT）
         → PD + α-β 平滑（死區、速度上限）
            → 更新「遊戲內準星」座標（非 OS 滑鼠）
               → HUD 疊加與記錄（延遲/命中/誤鎖）
```

---

## 訓練與推論（建議值）

- **訓練**：`imgsz=512`、`epochs=20–30`、`batch=16`；增強含 HSV 抖動、模糊、遮擋、JPEG 壓縮雜訊
    
- **驗證**：mAP@0.5、Precision/Recall、PR 曲線（特別看小物體召回）
    
- **推論**：Top-1/Top-k + 追蹤；主迴圈**不阻塞**、採用**最新可用結果**
    

---

## 評估指標與實驗設計

- **效能**：FPS（偵測/整體）、端到端延遲（ms）
    
- **準確**：命中率、誤鎖率、ID Switch（若使用追蹤）
    
- **操控**：取靶時間、過衝量（overshoot）
    
- **A/B**：無輔助 vs 低/中/高輔助強度；可參考 Fitts’ Law 任務變化
    

---

## 五週時程（里程碑）

- **W1**：資料計畫與合成器；錄影抽幀＋首批標註；前後端骨架
    
- **W2**：YOLOv10 微調（20–30 epochs）；前端打通 `/infer`；框＋準星顯示
    
- **W3**：選靶/追蹤（SORT/規則）；PD + α-β 平滑；蒐集指標
    
- **W4**：效能與穩定（FPS/延遲/誤鎖）；小型使用者測試
    
- **W5**：整合 Demo、技術報告、開源釋出（程式＋文件＋影片）
    

---

## 風險與對策

- **延遲過高**：縮解析度（320～512）、啟用 WebGPU/本機推論、非同步請求、只取 Top-1
    
- **誤鎖 HUD/非目標**：把 HUD 作為**負樣本**或前處理裁切
    
- **外觀變化**：合成器做色/亮度/配件抖動與部分遮擋；必要時少量再訓練
    
- **倫理/合規**：僅在授權單機/訓練場景啟用；不控制 OS 滑鼠；附使用指引與責任聲明

## 實作備忘（最小接口）

- **REST `/infer`（後端路線）**：`POST` 圖像（512×288）→ 回傳 `top`/`boxes`（xyxy、score、cls）
    
- **前端回圈**：每 33–50 ms 擷取 canvas → 非阻塞送出 → 使用**最新結果**更新準星
    
- **控制器**：`T` 開關、`←/→` 切換，PD + α-β + 速度上限
